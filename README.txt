BARCELONA SONRIE — WEB DE PROJECTE

Fitxers:
- index.html: pàgina d'inici
- clinic.html: la clínica, missió, visió, valors i equip
- tractaments.html: serveis odontològics
- contacte.html: dades de contacte i formulari de demostració
- css/style.css: disseny adaptable
- js/main.js: menú mòbil i interacció del formulari

IMPORTANT ABANS DE LLIURAR:
1. Verifica l'adreça exacta de la clínica en una font oficial.
2. Afegeix telèfon, correu i horaris oficials.
3. Afegeix els noms, fotos i titulacions reals de l'equip amb permís.
4. Confirma que els tractaments descrits coincideixen amb els serveis actuals.
5. El formulari és una demostració i NO envia informació.
6. Perquè el professor hi accedeixi per un enllaç, cal pujar la carpeta a un servei d'allotjament web estàtic, per exemple Netlify o GitHub Pages.
7. Mantén el contingut en català, com demana el projecte.

Les fotografies de mostra es carreguen des d'Unsplash i necessiten connexió a internet. Són imatges il·lustratives i no representen necessàriament les instal·lacions reals de la clínica.
